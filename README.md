# 📅 Расписание занятий ТУСУР — Группа 126-2 (ИРЭТ)

Автоматический генератор и виджет календаря iCalendar (`.ics`) для студентов группы **126-2** института радиоэлектроники и информационных технологий (**ИРЭТ**) ТУСУР.

Совместимо с **Apple Calendar (iOS / iPadOS / macOS)**, **Google Календарь (Android / Web)**, **Яндекс.Календарь**, **Microsoft Outlook** и любыми другими календарными приложениями.

---

## 🚀 Быстрый старт: Как добавить расписание прямо сейчас

### 🍏 Apple Calendar (iPhone / iPad / Mac)
1. **На Mac:** Дважды кликните по файлу `schedule-126-2.ics` → выберите календарь, в который хотите добавить события.
2. **На iPhone:** Отправьте файл себе в Telegram (в «Избранное») или откройте через «Файлы» → нажмите «Добавить все события».

### 📅 Google Календарь (Web / Android)
1. Откройте [calendar.google.com](https://calendar.google.com/) на компьютере.
2. В правом верхнем углу нажмите **Настройки (шестерёнка)** → **Настройки**.
3. В левом меню выберите **Импорт и экспорт** → выберите файл `schedule-126-2.ics` и нажмите **Импорт**.
4. Все пары на весь семестр появятся в вашем календаре и мгновенно синхронизируются с телефоном!

## 🏷️ Формат названий мероприятий

Каждое событие оформлено строго по вашим правилам:
`[<цвет-кружок> <тип пары>] <Название предмета>`

| Тип пары | Обозначение | Цвет / Эмодзи | Пример в календаре |
| :--- | :---: | :---: | :--- |
| **Лекция** | `Л` | 🟢 Зеленый | `[🟢 Л] Физика` |
| **Практика** | `П` | 🔵 Голубой / Синий | `[🔵 П] Английский` |
| **Лабораторная работа** | `ЛР` | 🟣 Фиолетовый | `[🟣 ЛР] Физика` |
| **Курсовая работа** | `КР` | 🌸 Розовый (сакура) | `[🌸 КР] Электроника` |
| **Курсовое проектирование** | `КП` | 🌸 Розовый (сакура) | `[🌸 КП] Инж. графика` |
| **Зачет** | `ЗАЧ` | 🟠 Оранжевый | `[🟠 ЗАЧ] Математика` |
| **Зачет с оценкой / Диф. зачет** | `ЗсО` | 🟠 Оранжевый | `[🟠 ЗсО] Математика` |
| **Экзамен** | `ЭКЗ` | 🔴 Красный | `[🔴 ЭКЗ] Физика` |
| **Самостоятельная работа** | `СР` | ⚪ Белый | `[⚪ СР] Математика` |
